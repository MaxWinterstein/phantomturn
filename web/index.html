    ⚙️ Assumptions

    Every default here was calibrated on one swimmer, a Forerunner 265 and a 50 m pool. If your numbers come out wrong, this is where to fix them.

    Leave blank to trust what the watch recorded. Set it if the watch had the wrong pool size — that makes every distance wrong by a fixed ratio and nothing in the data gives it away. Everything else here scales with it.
    auto works it out separately for each lap by measuring it against how long one length takes you in this swim — so a session where you lapped every length at first and then swam a continuous block comes out right in both halves. Put a number here instead to force it.
    auto scales it from the pool size — 80 strokes per 100 m, so 40 in a 50 m pool and about 14 in an 18 m one. A fixed number only means anything for one pool size.
    A cross-check on the stroke count; auto scales it from the pool too. When the two disagree the lap is reported as ambiguous and the watch's own label is kept.
    Overrides the watch's stroke classification with the thresholds above.
    Drops the gap between stopping the timer and saving. Only applied when the timer was never paused.
